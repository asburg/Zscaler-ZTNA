# Zero Trust Network Access (ZTNA) with Zscaler

This capstone project challenges student teams to critically assess and address the security vulnerabilities inherent in traditional perimeter-based and VPN-centric network access models within an education technology context. These legacy approaches often grant broad network access, increasing the attack surface and enabling lateral movement for adversaries once inside the network. Teams will design and prototype a modern Zero Trust Network Access (ZTNA) solution leveraging Zscaler Private Access (ZPA).

The project requires a comprehensive application of foundational cybersecurity principles, including in-depth vulnerability assessment, the principle of least privilege, and micro-segmentation. Students will move beyond theoretical understanding to hands-on implementation, demonstrating the ability to replace outdated security paradigms with a granular, identity-centric access model. This includes configuring cloud-native security platforms, integrating with identity providers, and defining fine-grained access policies.

The ultimate goal is to enhance the security posture of a simulated education technology environment by rendering internal applications invisible to unauthorized users and external scanners, thereby eliminating lateral movement risks. The project culminates in a detailed technical report, a functional prototype demonstrating ZTNA principles, and an analysis of future trends in Zero Trust security.
